# Monte Carlo Blackjack Simulation

This project uses Monte Carlo simulation techniques to model a simplified blackjack environment in Python.

The program repeatedly runs games with fixed dealer and player strategies, then estimates long-run statistics, such as:
- expected value (EV)
- win probability
- loss probability
- push probability

## Environment Conditions

- Cards are randomly generated between 1-10
- Both the player and dealer hit until 17 or higher
- Going above 21 means a loss
- Equal totals result in a push

## Example Output

- EV: -0.072702
- Probability of Winning: 40.7884%
- Probability of Losing: 48.0586%
- Probability of Pushes: 11.153%
